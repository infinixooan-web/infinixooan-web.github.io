# infinixooan.github.io

infinixooan의 개인 GitHub Pages 사이트입니다.

## 로컬에서 보기

정적 사이트라 파일을 브라우저로 바로 열어도 되고, 간단한 로컬 서버로 볼 수도 있습니다:

```bash
python -m http.server 8000
```

그 후 http://localhost:8000 접속.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 자동으로 https://infinixooan-web.github.io 에 배포합니다.
(저장소 Settings → Pages 에서 소스가 `main` 브랜치인지 확인하세요.)
